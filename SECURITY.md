# Security Policy

## Supported versions

Security fixes are provided for the latest version of Windhawk Badges on the `main` branch and the live website and Cloudflare Worker. Older versions are not actively supported.

## Reporting a vulnerability

Please do not share security problems in public GitHub issues, discussions, or pull requests.

When private vulnerability reporting is enabled, use the repository's [Security advisories](https://github.com/luizbizzio/windhawk-badges/security/advisories) page to submit a private report.

If this option is not available, email **contact@luizbizzio.com** with the subject **Windhawk Badges Security Report**.

Include these details when possible:

- A short description of the problem and its impact.
- The affected URL, file, or code version.
- Steps to reproduce the problem.
- A safe proof of concept, if available.

Please avoid testing that could damage data, affect other users, or interrupt the live service. Give the maintainer a chance to review the report before sharing details publicly.

## Scope

Examples of security issues include unsafe SVG or HTML content, script injection, unsafe external links, API abuse vulnerabilities, and exposed secrets.

For normal bugs and feature requests, use GitHub issues instead of a private security report.

## Response

Reports will be reviewed as soon as possible. The time required to fix an issue depends on its impact and complexity. No fixed response time is guaranteed.
