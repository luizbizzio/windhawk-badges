# Windhawk Badges

Badges for mods in the public Windhawk catalog.

**Website:** https://luizbizzio.github.io/windhawk-badges/

This independent community project is not affiliated with Windhawk.

## Features

- Ten badges: Users, Rating, Rating votes, Reviews, Version, Author, Updated, Published, License and Architecture.
- Twelve preset colors and custom six-digit HEX colors for both parts of the badge.
- Copy one badge's Markdown or all badges at once.
- Automatic updates based on the Windhawk catalog.
- Source on GitHub, public site on GitHub Pages, optional dynamic badge API on Cloudflare Workers.

## How to use

Open the [badge generator](https://luizbizzio.github.io/windhawk-badges/), search for a mod, choose a color and copy the Markdown.

The site runs on GitHub Pages. Cloudflare Workers is used **only to render dynamic SVG images**, not to host the website.

## Deploy GitHub Pages

1. Make this repository public, or use a GitHub plan that supports Pages for private repositories.
2. In **Settings > Pages**, select **GitHub Actions** as the source.
3. In **Actions**, run **Build and deploy GitHub Pages** on `main`.

The daily workflow publishes the site and catalog data. Until the Worker is connected, preset-color badges use GitHub Pages SVGs.

## Enable custom HEX badges

1. Deploy the Worker from the GitHub repository through Cloudflare Workers Builds, using `npx wrangler deploy`. The Worker code is in `worker/index.js` and its configuration is `wrangler.jsonc`.
2. Cloudflare will give you a hostname such as `https://windhawk-badges.YOUR-SUBDOMAIN.workers.dev`.
3. Edit `site/config.js` and put your **real** Worker hostname in `window.WINDHAWK_BADGES_WORKER_URL`. Do not include a trailing slash.
4. Commit the change. GitHub Pages will redeploy and all badge links generated by the website will use the Worker.

Without a configured Worker URL, the site disables copy actions for custom HEX instead of providing broken links.

## Dynamic badge URLs

```text
https://windhawk-badges.YOUR-SUBDOMAIN.workers.dev/badges/taskbar-zones/users.svg?color=ff5733&labelColor=24292f
```

The Worker caches Windhawk catalog data for up to six hours. Badge responses are cacheable for one hour; GitHub may cache displayed README images longer. The `users` value is a catalog user count, not a download counter.

## Development

Run `npm test` for Worker tests, or `python -m unittest discover -s tests -p 'test_generate.py' -v` for the static generator.

The generated `dist/` directory is published by GitHub Actions, not committed to the repository. The Worker does not serve frontend assets.
