# Windhawk Badges

Create automatically updated SVG badges for any mod in the public Windhawk catalog.

**Website:** https://luizbizzio.github.io/windhawk-badges/

This is an independent community project. It is not affiliated with Windhawk.

## Features

- Eleven badge types: Users, Rating, Rating votes, Reviews, Version, Author, Updated, Published, License, Architecture, and **Mod name**.
- Five styles: Classic, Flat, Flat square, Rounded, and Pill.
- Two sizes: Normal and Compact.
- Two label modes: Full (`Windhawk users`) and Short (`Users`).
- Twelve preset colors, or any six-digit HEX color for the value and label.
- Copy Markdown or the image URL for each badge. You can also copy all badges at once.
- Badge values update from the public Windhawk catalog. New SVGs are generated by Cloudflare Workers.

## How to use

1. Open the [badge generator](https://luizbizzio.github.io/windhawk-badges/).
2. Search for a mod.
3. Choose the color, style, size, and labels.
4. Copy the Markdown into a GitHub README.

The **Mod name** badge displays only the name of the selected mod. The copied Markdown links the image to the mod's official Windhawk page, using `https://windhawk.net/mods/<mod-id>`.

## Badge URLs

The Worker API runs at `https://windhawk-badges.luizbizzio.workers.dev`.

Default badge:

```text
https://windhawk-badges.luizbizzio.workers.dev/badges/taskbar-zones/users.svg
```

Compact, pill style, short label, and custom HEX:

```text
https://windhawk-badges.luizbizzio.workers.dev/badges/taskbar-zones/users.svg?style=pill&size=compact&labelMode=short&color=ff5733&labelColor=24292f
```

Mod name:

```text
https://windhawk-badges.luizbizzio.workers.dev/badges/taskbar-zones/mod.svg?style=rounded
```

All appearance parameters are optional:

| Parameter | Supported values | Default |
| --- | --- | --- |
| `style` | `classic`, `flat`, `flat-square`, `rounded`, `pill` | `classic` |
| `size` | `normal`, `compact` | `normal` |
| `labelMode` | `full`, `short` | `full` |
| `color` | 12 palette names or six-digit HEX | `blue` |
| `labelColor` | 12 palette names or six-digit HEX | `555555` |

The short label mode shortens `Windhawk users` to `Users`, `Windhawk rating` to `Rating`, and `Rating votes` to `Votes`. Other labels stay the same. The Mod name badge has only one colored segment, so it does not use a label or `labelColor`.

All older URLs remain supported, including `/badges/<mod-id>/<kind>.svg` and `/badges/<mod-id>/<kind>/<color>.svg`.

## Hosting and updates

- **GitHub Pages** hosts the website at https://luizbizzio.github.io/windhawk-badges/.
- **Cloudflare Workers** generates the SVG badges at the URL above.
- **Windhawk** provides the public catalog at https://mods.windhawk.net/catalogs/en.json.
- The Worker caches catalog data for up to six hours. The SVG response is cacheable for one hour. GitHub may cache README images for longer.
- The GitHub Actions workflow publishes site data and fallback classic badges daily. Custom styles are generated by the Worker.

The repository can remain private while the website and badge API are public. When the project is ready, the repository can be made public for stars and contributions.

## Development

The Worker requires Node.js 20 or newer:

```bash
npm install
npm test
npm run dev
```

To deploy the Worker manually, run `npm run deploy` after logging in to Cloudflare. Normally Cloudflare deploys new commits from `main` automatically.

The GitHub Pages deployment is configured in `.github/workflows/deploy.yml`.
